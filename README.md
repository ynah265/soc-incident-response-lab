# SOC & Incident Response Lab

## Project status
In progress — planning and documentation started.
The lab software has not been installed yet.

## Overview
This project documents my progress building a beginner security
operations lab. I will use Wazuh to collect and investigate security
events from a monitored computer.

A Security Operations Center (SOC) monitors systems, investigates
suspicious activity, and helps respond to security incidents.

## Learning goals
- Understand how security logs are collected and analyzed.
- Set up Wazuh and connect a monitored computer.
- Generate controlled test events inside my own lab.
- Investigate failed logins and changes to monitored files.
- Use Nmap to identify exposed services in the lab.
- Document evidence, findings, and response steps.

## Planned tools
- Wazuh for security monitoring and investigation.
- A Linux virtual machine for the Wazuh server.
- A lab endpoint to generate activity for monitoring.
- Nmap for discovering ports and services.
- GitHub for documentation and version history.

The exact setup will be finalized after checking available resources.

## Lab boundaries
Testing will be limited to systems I own and designate for this lab.
Published evidence will exclude passwords, access tokens, and
personal information.
